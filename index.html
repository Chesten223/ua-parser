Frequently Asked Questions

What is a User-Agent string?
A User-Agent string is an HTTP header your browser sends to every website. It identifies your browser type, version, operating system, and device so servers can serve compatible content.
How accurate is this parser?
The parser uses comprehensive pattern matching for all major browsers and operating systems. It handles modern Chromium-based browsers, Firefox, Safari, Edge, and legacy browsers accurately.
Is my data stored anywhere?
No. All parsing runs entirely in your browser using JavaScript. No UA string is transmitted to any server. The last 5 parses are kept in memory only and disappear when you close the tab.
